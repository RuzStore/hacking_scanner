FriendScan Security Baseline

Prinsip

FriendScan tidak boleh menganggap informasi pribadi dapat diakses hanya karena seseorang mengetahui identifier atau token.

Target kontrol

- server-side authorization
- token expiry
- token replay protection
- rate limiting
- secure session handling
- input validation
- audit logging
- consent enforcement
- revocation
- secret management

Status

Kontrol di atas merupakan target desain.

Keberadaan daftar ini bukan bukti bahwa kontrol sudah diimplementasikan atau diuji.

Batas versi awal

Versi awal tidak menyimpan:

- lokasi pengguna
- fingerprint perangkat
- nomor telepon
- email pribadi
- kredensial akun sosial
- data CCTV
