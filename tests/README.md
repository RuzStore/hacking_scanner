FriendScan Test Plan

Pengujian yang akan ditambahkan secara bertahap:

1. API health check
2. Invalid token
3. Token expiry
4. Token replay
5. Authorization bypass
6. Consent enforcement
7. Consent revocation
8. Rate limiting
9. Input validation
10. Audit logging

Setiap test harus memiliki:

- kondisi awal
- perintah menjalankan
- expected result
- actual result
- exit status

Test yang belum dijalankan tidak boleh disebut sebagai test yang berhasil.
